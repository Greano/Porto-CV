# Portfolio website v2

1. Open `index.html` in your browser to preview.
2. Edit the values in `content.js` for your name, description, projects and links.
3. Edit the achievements, startup, committee, and speaker placeholders directly in `index.html`.
4. Put `professional-cv.pdf` and `academic-cv.pdf` in `assets/` to activate CV links. Do not publish private contact details you do not want public.
5. To publish: create a public GitHub repository, upload `index.html`, `content.js`, and the `assets` directory. In repository Settings > Pages, select Deploy from a branch > main > /(root). The public URL will appear after GitHub finishes publishing.
6. Verify all claims, especially award levels and event names, before publishing.

The website is a demo and includes placeholders, not fabricated accomplishments. It requires no build system.
